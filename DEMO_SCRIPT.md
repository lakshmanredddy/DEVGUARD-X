# DEVGUARD-X 3-Minute Demo Script

## 0:00 — Problem

Show the dashboard and say:

"Developers don't just write code. A production issue requires investigation, test analysis, implementation, validation, review and release preparation. These steps are often fragmented across tools."

## 0:25 — Issue

Open DG-1042:

"Users receive HTTP 500 when uploading PDFs larger than 10 MB."

## 0:40 — Bob

In IBM Bob IDE, show the repository and run `/init`.

Switch to Plan mode and ask Bob to inspect the target application and plan the workflow.

Then use the DEVGUARD Orchestrator mode.

## 1:05 — Parallel analysis

Show the Debugger, Test and Security findings.

Emphasize that these are independent concerns and can be delegated to focused subtasks/subagents.

## 1:35 — Implementation

Let Bob implement the safe fix and add regression tests.

Run the test suite.

## 2:05 — Review

Use Bob's code review workflow and show the final diff and test evidence.

## 2:25 — Dashboard

Return to DEVGUARD-X and show the workflow and release-readiness screens.

## 2:45 — Impact

Show actual measured before/after timings.

Do not invent metrics.

## 2:55 — Closing

"DEVGUARD-X turns an issue into an evidence-backed, release-ready change while keeping the developer as the final approval gate."
